# Artículo: Industria Petrolera Global vs. Potencial de Mendoza

## Archivos incluidos
- `articulo_petroleo_mendoza.Rmd` — Artículo completo en RMarkdown

## Requisitos
- R (versión 4.0 o superior)
- RStudio (recomendado)
- Paquetes de R:
  ```r
  install.packages(c("distill", "rmarkdown", "ggplot2", "dplyr", "knitr"))
  ```

## Cómo renderizar
1. Abre el archivo `.Rmd` en RStudio
2. Haz clic en el botón "Knit" o ejecuta:
   ```r
   rmarkdown::render("articulo_petroleo_mendoza.Rmd")
   ```
